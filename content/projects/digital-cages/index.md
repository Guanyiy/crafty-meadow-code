This project analyzed millions of actigraphy time-series observations from digitally monitored mice.

Methods used:

- PCA  
- **Sparse PCA (NExOS)** for interpretability  
- k-means and hierarchical clustering  
- Rolling-window variance and circadian features  

I discovered that **sparse PCA produced behaviorally meaningful latent axes**, allowing clustering to identify interpretable behavioral states such as exploration, resting, and transition periods.

This project strengthened my belief that sparsity is not only a dimensionality-reduction tool—it's an interpretability tool.
