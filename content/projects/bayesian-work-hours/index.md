I built a hierarchical Bayesian model for work hour patterns across 20+ industries using **rstan**, focusing on:

- Prior specification  
- Reparameterization (non-centered)  
- Divergence elimination  
- Monitoring R-hat, ESS, energy diagnostics  
- Posterior predictive checks  
- LOO-CV for model comparison  

This project strengthened my computational perspective:  
good Bayesian models are *engineered*, not just specified.
